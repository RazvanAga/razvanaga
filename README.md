## About this repo

This is the source of [razvanaga.com](https://razvanaga.com) — a portfolio built as a faux terminal:

- **Next.js 16** (App Router) + **React 19** + **Tailwind CSS 4**, fully static
- A working in-browser terminal with `ls` / `cd` / `cat`, tab completion, and command history
- Content lives in plain markdown files rendered through a virtual file system

```
/ > ls
career  projects  contact  README.md
/ > cat career/experience.md
```
